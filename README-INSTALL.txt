INSTALL

1. Stop the development server:
   Ctrl + C

2. Extract THIS ZIP directly into:
   D:\cic-latest-website\cic-website

3. Choose YES / REPLACE when Windows asks to replace files.

4. Make sure Lucide is installed:
   npm install lucide-react

5. Start:
   npm run dev

6. Open:
   http://localhost:3000
